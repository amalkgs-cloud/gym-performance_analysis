# Gym Performance & Training Analytics

## Project Overview
A beginner-friendly data analytics project exploring gym workout
patterns using Python, Pandas, Matplotlib, and SQL.

## Objectives
- Analyse workout frequency and duration.
- Compare training time across muscle groups.
- Calculate estimated training volume.
- Use SQL to summarise workout sessions.
- Visualise workout patterns with charts.

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- SQLite
- Google Colab
- GitHub

## Dataset
The dataset contains 12 illustrative workout records, including:
- Workout date and type
- Muscle group
- Session duration
- Number of exercises, sets, and repetitions
- Recorded exercise weight

## Analysis Performed
1. Dataset inspection and missing-value checks
2. Workout frequency analysis
3. Training time by muscle group
4. Estimated training volume calculations
5. SQL queries for workout summaries and longest sessions
6. Data visualisation

## Repository Structure
- `data/workout_data.csv` — sample dataset
- `gym_performance_analysis.ipynb` — Python analysis and charts
- `sql/gym_analysis.sql` — SQL queries
- `README.md` — project documentation

## Important Note
The dataset is illustrative and does not represent real gym members
or actual personal workout measurements.
